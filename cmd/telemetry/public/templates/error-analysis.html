Query this data directly

Every table on this page comes from a public JSON endpoint. All of them take the filters above.

GET /api/errors
Everything on this page: summary, causes, apps, exit codes, failures over time and stuck runs.
GET /api/causes
Failure causes with apps, setups, first and last seen, trend and example run IDs. examples=full adds the example runs with traces; limit up to 200.
GET /api/app-errors
Apps with at least one failure: runs, outcomes, failure rate, setups, top cause, last failure and success, failing now.
GET /api/records
Single runs with merged metadata, stage timestamps and the trace. Filter with cause, message, app, exit_code, category, status, execution_id, random_id, search, os; page with page, limit (up to 100) and sort.

Filters: days (1 to 365), repo (ProxmoxVE, DevScripts, external), slug (owner/repo), platform (pve, incus), type (lxc, vm, turnkey, pve, addon, tool, install, all; rates default to LXC and VM), app (exact name). status takes success, failed, aborted, unknown (no result) or in_progress.

This view as JSON: /api/errors
