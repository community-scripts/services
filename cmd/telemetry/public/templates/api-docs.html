Proxmox VE Helper-Scripts
Dashboard Errors Scripts
-

API

JSON over GET at https://telemetry.community-scripts.org.

Access

Without a header, runs come without error, error_message, error_step and failed_command, and causes are exit codes.

Authorization: Bearer <trace password> adds them and groups causes by message. It also allows POST /api/github/create-issue.

Any other Authorization answers 403. The limit is 300 requests a minute per address, then 429.

Filters

ParameterValues
days1 to 365
repoProxmoxVE, DevScripts, external, all
slugowner/repo
platformpve, incus, all
typelxc, vm, turnkey, pve, tool, addon, all, install (all but pve, tool, addon)
appexact script name

Endpoints

EndpointDefaultsReturns
/api/errors7 days, installSummary, causes, apps, exit codes, failures over time, stuck runs
/api/causes7 days, installFailed runs grouped by cause. limit (50, up to 200); examples=full adds up to three runs per cause
/api/app-errors7 days, installApps with failed runs. limit (100, up to 500)
/api/records1 day, allOne record per run. status (success, failed, aborted, unknown, in_progress), cause, exit_code, category, os, search, execution_id, random_id, message (password only), page, limit (50, up to 100), sort
/api/dashboard1 day, installSummary, top apps, breakdown, top causes, failing apps, failure matrix, timeline
/api/scripts30 days, allOne entry per script. Takes days, repo, slug and platform only
/api/script-detail30 days, allOne script over time, its causes and newest runs. Needs app
/api/repo-slugs30 daysRepositories with their run counts
/api/exit-codesExit codes with their descriptions

Examples

curl -s -H "Authorization: Bearer $PASSWORD" "https://telemetry.community-scripts.org/api/causes?days=7&limit=20"
curl -s -G -H "Authorization: Bearer $PASSWORD" "https://telemetry.community-scripts.org/api/records" \
  --data-urlencode "days=7" --data-urlencode "status=failed" --data-urlencode "limit=100" \
  --data-urlencode "cause=E: Unable to locate package libvips-dev"
curl -s -H "Authorization: Bearer $PASSWORD" "https://telemetry.community-scripts.org/api/script-detail?app=immich&days=30"
